# README.md

`Raw_data` directory contains the files used pre-filtering and cleaning:

- character_key.csv = character definitions 
- character_matrix.csv = character values collected for species
- locality.csv = sample location and GenBank accession numbers
- metadata.csv = metadata for phylogeny and tables
- models.csv = partions and evoluitonary models for phylogeny
- Oreophryne_sensu_lato.csv = names of Oreophryne species as currently defined, citations, and taxonomic transfers
- Oreophryne_Type_Localities...csv = citations and gps data for type localities
