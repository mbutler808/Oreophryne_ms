# README.md

`Processed_data` directory contains data post-filtering and cleaning, used by manuscript files for creating tables:

- localities.RDS = Table 1. sample location and GenBank accession numbers
- character_key.RDS = Table 2. character definitions 
- character_matrix.RDS = Table 3. character values collected for species
- genus_types.RDS = Table 4. Type species by genus for phylogenetic definition
- metadata.csv = metadata for phylogeny and tables
- models.RDS = Supplementary Table 1. partions and evoluitonary models for phylogeny
- Oreophryne_sensu_lato.rds = Supplementary Table 2. names of Oreophryne species as currently defined, citations, and taxonomic transfers
- Oreophryne_Type_Localities...csv = citations and gps data for type localities
