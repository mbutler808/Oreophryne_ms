# README.md

This directory contains all of the inputs and code needed to reconstruct the phylogeny using IQTREE2 and the output files. Please see `README` files within each directory for explanation 

-  `input`        Input files
-  `model_search` 
  + `iqtreerun_bestmodel.sh` = shell script to generate phylogeny
  + output files for the best model determined by PartitionFinder
  + `bestmodel_` = subdirectories for alternate partition schemes
